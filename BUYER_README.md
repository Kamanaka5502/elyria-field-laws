# Buyer Readme

## What this repository proves

Elyria Field Laws is an executable movement-governance runtime for deciding whether a proposed action may lawfully bind consequence.

The governing question is:

> Can inadmissible movement become protected consequence?

The runtime does not merely log, approve, score, or explain an action. It resolves whether the action may acquire binding status at the consequence boundary.

## Why it matters

Most systems govern process surfaces. Elyria Field Laws governs the binding condition itself.

Run:

python -m pytest -q
python demo.py
python adversarial_demo.py

All examples are synthetic and contain no customer data, secrets, credentials, or production policy packs.
