# End-to-End Corridor Proof Pack

## Core Claim

The corpus becomes product-grade when one bounded corridor proves the entire chain from proposed movement to protected-effect prevention or admission.

The proof pack must show one movement entering the field, resolving through the kernel, producing a receipt, and replaying legitimacy.

---

## Corridor Shape

A bounded corridor must define:

```text
corridor_id
movement_type
protected_effect_id
lawful_region_model
standing_basis
failure_classes
kernel_outcomes
receipt_schema
replay_requirements
```

The corridor must be narrow enough to replay deterministically.

---

## Minimum End-to-End Flow

```text
1. propose movement
2. evaluate lawful region R
3. evaluate current standing
4. evaluate changed-condition / reentry state
5. resolve kernel decision
6. map protected effect
7. guard protected effect formation
8. issue receipt
9. verify legitimacy replay
10. emit proof-surface verdict
```

This is the first complete product corridor.

---

## Required Proof Objects

The corridor must produce:

```text
movement object
region receipt
kernel receipt
effect guard receipt
runtime receipt
replay receipt
proof-surface receipt
```

Each object must preserve the same movement identity and protected-effect identity.

---

## Valid Corridor Result

A valid corridor result must show either:

```text
ALLOW -> protected effect may form -> receipt -> legitimacy replay valid
```

or:

```text
NON_ALLOW -> protected effect prevented -> receipt -> legitimacy replay valid
```

Anything else is control-surface-only.

---

## Failure Cases

The first corridor must include negative cases:

```text
hard gate failure
redirect laundering
execution replay only
protected effect formed under non-allow
missing protected-effect map
missing failure class
non-replayable prevention
```

These prove the runtime can distinguish admissible governance from collapsed control surfaces.

---

## Product Boundary

This proof pack should not attempt to cover every system.

It should prove one bounded consequence corridor.

One corridor is enough if it preserves the full relation:

```text
movement -> standing -> kernel -> protected effect -> receipt -> replay -> proof surface
```

---

## Doctrine

The next maturity step is not more theory.

The next maturity step is one complete corridor where the field laws execute together.

```text
One corridor. One protected effect. One replayable proof.
```
