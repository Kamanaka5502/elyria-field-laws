# Trajectory Breach Theorem

## Core Claim

A breach is not a failed endpoint.

A breach is attempted movement against lawful traversal structure.

Breach does not create authority.

Breach reveals the boundary.

---

## Formal Context

Movement is evaluated as traversal:

```text
M(tau)
```

The lawful region of continuation is:

```text
R = { z | A(z) >= 0, Phi(z) >= 0, U(z) = 1 }
```

A trajectory breach occurs when a material traversal point exits lawful continuation geometry:

```text
exists tau_b such that M(tau_b) notin R
```

The breach point `tau_b` is the first material point where admissibility, capacity, authority-validity, lineage, witness, or consequence-boundary control fails.

---

## Theorem

If a proposed movement breaches lawful traversal geometry, continued consequence admission must be suspended until the breach is resolved.

The breach resolution sequence is:

```text
Breach -> Halt -> Judgement -> Restart
```

Where:

```text
Breach = traversal exits lawful geometry
Halt = violating trajectory is stopped
Judgement = state is evaluated against invariant law
Restart = continuation resumes only through a lawful transition
```

Restart does not erase breach.

Restart must preserve invariant law.

---

## Breach Is Not Permission

A breach may show that motion occurred.

It does not show that motion had standing.

```text
breach != authority
breach != admissibility
breach != continuation
breach != consequence permission
```

A system that treats breach as permission is not governing movement.

It is inheriting violation.

---

## Breach Failure Classes

Trajectory breach may be classified as:

```text
ADMISSIBILITY_BREACH
CAPACITY_BREACH
AUTHORITY_BREACH
LINEAGE_BREACH
WITNESS_BREACH
CONSEQUENCE_BOUNDARY_BREACH
ROUTE_STANDING_BREACH
TRANSFER_CONTINUITY_BREACH
```

These classes explain why the trajectory could not lawfully continue.

---

## Relation to Endpoint Validity

A trajectory may breach even when origin and destination appear valid.

Endpoint validation can hide breach.

Path validity must expose breach.

```text
valid endpoints do not repair an unlawful traversal
```

---

## Relation to Replay

Legitimacy replay must preserve the breach point and the breach reason.

A replay that reconstructs only the final halt or final refusal but not the breach condition is execution replay only.

Breach replay must preserve:

```text
breach point
failed dimension
state before breach
state at breach
kernel decision
halt reason
restart basis if any
```

---

## Doctrine

Breach is where unlawful movement becomes visible to the resolving field.

The proof is not that breach was observed.

The proof is that breach did not acquire lawful consequence status.

```text
Breach reveals boundary.
It does not create standing.
```
