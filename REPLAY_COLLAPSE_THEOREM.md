# Replay Collapse Theorem

## Core Claim

Replay collapse occurs when a system can reproduce a terminal outcome while losing the admissibility structure that made the original decision lawful or non-lawful.

A replay that preserves outcome but loses legitimacy is not a governance witness.

It is execution history preservation.

---

## Theorem

Let `Replay_E(M)` be execution replay.

Let `Replay_L(M)` be legitimacy replay.

```text
Replay_E(M) = reproduced terminal behavior
Replay_L(M) = reconstructed admissibility basis
```

Then:

```text
Replay_E(M) does not imply Replay_L(M)
```

A system may reproduce the same output, same refusal, same terminal state, or same visible effect while failing to preserve the lawful basis of the movement.

---

## Collapse Condition

Replay collapses when any required legitimacy dimension is missing, mismatched, or unrecoverable.

Required legitimacy dimensions include:

```text
movement object
origin state
target state
authority standing
evidence freshness
lineage condition
recovery posture
consequence exposure
witness object
trajectory validity
admissibility distance
law version
kernel resolution
protected effect status
```

If the replay cannot reconstruct these dimensions, it is not legitimacy replay.

---

## Why This Is Different From Ordinary Replay

Ordinary replay asks:

```text
Can the same result be reproduced?
```

Legitimacy replay asks:

```text
Can the same consequence-state truth be reconstructed?
```

That distinction matters because governance is not the repetition of outcome.

Governance is preservation of the lawful reason movement did or did not acquire consequence status.

---

## Failure Examples

Replay collapse occurs when:

```text
same terminal output is reproduced but authority standing is missing
same refusal label is reproduced but evidence freshness is missing
same receipt is reproduced but lineage cannot be reconstructed
same bind status is reproduced but admissibility distance is absent
same halt outcome is reproduced but trajectory validity is unavailable
```

These are not minor metadata losses.

They are legitimacy losses.

---

## Relation to Projection Error

Replay collapse is a projection error.

The replay surface becomes mistaken for the native resolving relation.

The system sees the shadow and treats it as the structure.

```text
outcome replay = projection
legitimacy replay = admissibility reconstruction
```

Projection may witness.

It may not replace.

---

## Relation to Receipts

A receipt that records only the final decision is insufficient.

A receipt must preserve the admissibility path or enable deterministic reconstruction of the admissibility path.

Without that, the receipt documents execution but does not prove legitimacy.

---

## Field-Law Rule

The kernel rule remains:

```text
BIND(M) is defined only when K(M) = ALLOW.
```

Replay must verify not only that `BIND(M)` was or was not defined, but why that status followed from the field conditions.

---

## Doctrine

A system that replays consequence while losing admissibility has not preserved truth.

It has preserved motion without standing.

```text
Replay collapse is the loss of lawful consequence-state truth under reproduced outcome.
```
